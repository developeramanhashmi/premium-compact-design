# Portfolio and Admin UI

Build the PRD's public portfolio and `/admin` experience with a premium, compact visual system. Use the requested charcoal canvas and restrained mint, violet, and amber accents, with crisp typography, short cards, and no oversized panels.

## Scope
- Public home: responsive navigation, hero, about/stats, featured work with category filters, skills, experience, testimonials, writing, contact, and footer.
- Admin: compact overview and navigation for profile, projects, skills, experience, testimonials, articles, inbox, and appearance/settings. Include lightweight interface interactions and realistic sample entries.
- Keep this pass focused on UI and local prototype behavior. Authentication, persistent data, uploads, real analytics, and production integrations remain for a later request.
- Give `/` and `/admin` their own page metadata and keep the shared shell clean.

## Technical details
- Use TanStack Start routes already in the project and the existing Button, icon, and token conventions.
- Add a route-level admin screen, shared visual tokens, accessible responsive layouts, and focused tests for route matching.
- Use the generated portfolio artwork as the public home visual; do not introduce new dependencies.
